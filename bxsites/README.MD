# BXSITES

Official logo repository for **bxSites**, a fast, open-source static site generator for BoxLang that turns Markdown into themed, searchable websites. It supports documentation, blogs, marketing sites, and knowledge bases with no JavaScript build step or server required.

[Website](https://bxsites.io/) · [GitHub Repository](https://github.com/ortus-boxlang/bx-sites)
